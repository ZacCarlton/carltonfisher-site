Software Development

We write custom software: web applications, internal tools, data systems, and the code that runs equipment. We build it so your staff, or the next company you hire, can run it and change it after we are gone.

When to call us

  • A spreadsheet or paper process has outgrown itself.
  • You own software nobody can change anymore.
  • A vendor product almost fits and you need the rest built.
  • You need a tool built to a state or federal requirement.

What you get

  • The working software, set up where you run it.
  • The source code, in your own account from the first day.
  • Written setup and operating instructions.
  • Test results.
  • A handover session with your staff.

How it runs

  1. First call.
  2. Written scope and estimate with a ceiling.
  3. We build in short steps and show you working software every two weeks.
  4. Testing, handover and training.

Questions

Who owns the code?

You do. It sits in your account from the first day.

Can you work alongside our IT company?

Yes. We work with whoever runs your systems now and leave them written instructions.

Do you use AI tools when you write code?

Sometimes, for drafting. We tell you where, and none of your data goes into an AI tool without your written OK.
